================================================================================
  快速开始 (5 分钟)
================================================================================

1. 安装依赖:
   $ cd h:\easicoin
   $ pip install -r requirements.txt

2. 验证安装:
   $ python verify_installation.py

3. 运行示例 (无需 API 密钥):
   $ python easicoin_api/examples/example_public_data.py

4. 获取 API 密钥:
   访问 https://www.easicoin.io 创建 API 密钥

5. 设置环境变量:
   $ set EASICOIN_API_KEY=your_key
   $ set EASICOIN_API_SECRET=your_secret

6. 运行私有 API 示例:
   $ python easicoin_api/examples/example_private_api.py
